Add Mapbox keys

Optional: online search and speed-limit filling
Done
1
Make a Mapbox accountAt account.mapbox.com. The free tier covers personal driving.
2
Get two keysYour default public token (pk.) is there already. Create a token, keep its public scopes, and also check DOWNLOADS:READ so it starts with sk.
3
Open GalaxyOn this device: Device › This Device › Remote Access › Set Up, then open its link on your phone.
4
Paste both keysIn Galaxy: Navigation & Maps › App Keys. The public key is for search, the secret one for routes.
The keys stay on this device. Search and routes work as soon as they're saved.
