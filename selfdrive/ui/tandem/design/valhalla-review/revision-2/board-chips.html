Recalculating route

An active trip needs a replacement route.

Use the existing bottom-left status-chip placement and dark fill. Keep the time, distance-left and live street in the normal bottom bar. Hide stale turn guidance independently.

Routing and existing statuses together

Recalculation overlaps an existing steering-paused status.

Use the existing stack and spacing. Routing is informational and yields to safety alerts; it does not replace or recolor steering warnings.

Online failed; offline route works

Online is preferred, but its route request fails and a usable offline route succeeds.

Using offline maps appears briefly in the existing chip stack, then fades. The time/street layout stays in place.

Offline only, route unavailable

Offline maps only is on but a usable local route is unavailable.

The warning uses the existing chip; no online request is made. This example has no previous route estimate, so the time fields show dashes while the available street stays visible.
