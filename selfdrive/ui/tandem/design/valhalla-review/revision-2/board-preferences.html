Navigation preferences

Revision 2 · Approved references · Conditions and full-size images are in the gallery

Prefer online

Offline maps only is off; Online is selected.

Use a valid online route when it succeeds. If it is unavailable or fails, try the downloaded offline route once. Proposed default: this setting, with Offline maps only off.

Prefer offline

Offline maps only is off; Offline is selected.

Try a usable local route first. Missing coverage/data, a local failure, or no route triggers one online attempt if online routing is usable.

Offline maps only

Offline maps only is on.

No online routing request and no online routing fallback. Preferred maps is disabled and remembers its prior selection for when the override is turned off. Search remains a separate online feature.

Offline only, maps missing

Offline maps only is on, but Iowa offline routes have not been downloaded.

Keep the strict choice. The Offline Maps row leads to the existing region panes to obtain the missing maps. Do not silently use online routing.
